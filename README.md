# BITree 理枝

<img src="assets/brand/bitree.svg" width="160" alt="BITree 理枝 logo" />

BITree 是面向北京理工大学的跨平台工具集，中文名“理枝”，谐音“荔枝”。

>
> 本项目绝不收集您的任何个人信息，所有数据均在本地处理。您输入的校园账号密码仅用于登录认证系统并获取访问凭据以获取必要个人信息，本项目没有任何的后端服务器，也不会将您的账号密码上传到任何地方。
